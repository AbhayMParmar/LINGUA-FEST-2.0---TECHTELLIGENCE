#🎤 LINGUA-FEST 2.0 - TECHTELLIGENCE

✨ LINGUA-FEST 2.0 is a dynamic and responsive scoreboard web application designed specifically for managing school-level and interschool competitions. It provides real-time score updates, round-based evaluation, and an interactive leaderboard experience using modern web technologies and Firebase.

📌 Overview

LINGUA-FEST 2.0 is built to simplify the process of managing competition scores in events like:

📝 Poetry Recitation
📖 Story Telling
🎙️ Elocution
🗣️ Debate

The platform enables administrators to efficiently input and update scores while instantly reflecting results on a live leaderboard for students and faculty.

✨ Features
🔥 Real-time Score Updates using Firebase
🏫 Interschool Competition Support
📊 Round-based Scoring System
📈 Dynamic Leaderboard (auto-updated)
📱 Fully Responsive Design (mobile-friendly)
🛠️ Admin Dashboard for easy control
🧠 How It Works
Admin logs into the dashboard
Selects event category (Poetry, Debate, etc.)
Inputs marks for each participant
Data is stored in Firebase
Leaderboard updates instantly in real-time
🛠️ Tech Stack
🌐 HTML5 – Structure
🎨 CSS3 – Styling & Responsive Design
⚙️ JavaScript (Vanilla JS) – Functionality
🔥 Firebase – Real-time database & backend
